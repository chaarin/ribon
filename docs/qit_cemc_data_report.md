## 확인 결과

### 1. 편마모가 실제로 뚜렷함 → 프로젝트 차별점의 근거

- 편마모 지수 (max−min)/mean 중앙값 0.39, 68개 Cycle 중 **41개가 0.3 이상**
- 가장 많이 닳은 날이 특정 날에 고정되지 않음 (E1 20회, E2 19회, E3 16회, E4 13회)
- **가장 많이 닳은 날 기준으로는 Cycle 31에 VBmax 0.3 mm에 도달하지만, 4날 평균 기준으로는 Cycle 53에야 도달한다.**
  평균만 보면 한계를 22 Cycle 늦게 알아차린다는 뜻이고, 날별 분석이 필요한 이유를 데이터로 보여준다.

### 2. 공구 1개의 수명 전체 기록 (run-to-failure)

- Cycle 1~68 연속 기록, 평균 VB 0.16 mm(1~20) → 0.42 mm(61~68)
- 공구가 1개뿐이므로 **학습/평가는 반드시 시간 순서로 나눈다** (앞 Cycle로 학습, 뒤 Cycle로 평가). 무작위 분할은 미래 정보가 섞여 성능이 부풀려진다.

### 3. 라벨 노이즈가 큼 (주의)

- 마모는 물리적으로 줄어들 수 없는데, 날마다 0.03 mm 이상 감소한 경우가 13~16번 있다 (최대 −0.23 mm).
  치핑(날 일부 탈락) 또는 현미경 측정 편차로 보인다.
- 영향: Cycle 단위 날별 예측 오차의 하한이 높다. 모델 평가 시 이 점을 함께 보고하고, 라벨 평활화(이동 최대값 등) 여부를 실험으로 비교한다.
- 직전 Cycle 대비 증가량(급속 마모 판단)도 노이즈에 민감하므로 기준값 조정이 필요할 수 있다.

### 4. 끝날 라벨의 튀는 값 (프로젝트 라벨에는 영향 없음)

- Cycle 54 끝날 Edge 4: 0.6556 (앞뒤 Cycle은 0.06 수준) → 소수점 오기로 보임
- Cycle 63 끝날 Edge 3: 0.912 (앞뒤 0.08~0.09) → **같은 Cycle에 축 방향 힘 Fz rms가 18.3으로 주변(7~8)의 2배 이상 튐.**
  오기가 아니라 끝날 치핑 같은 실제 사건일 가능성이 있다. 이상 감지 사례로 활용할 수 있다.

### 5. 신호에서 확인한 것

- **스핀들 회전 주파수 약 23.2 Hz (약 1,390 rpm)**: 회전 동력계의 Fx 스펙트럼 최대 성분. 공개 자료에 없던 절삭 조건으로, Φ10 공구 기준 절삭속도 약 44 m/min (Ti 건식 가공에 타당한 범위).
- **힘 신호에 느린 영점 드리프트**가 있음 (한 Cycle 동안 |F| 평균이 16 → 124). 0.1초 이동평균을 빼서 제거하고 빠른 출렁임만 특징으로 사용.
- Cycle당 절삭 시간 대부분 8.4분 안팎 (Cycle 39만 7.2분), 전체 누적 약 577분.

## 날별 신호 분리 시도 (결과: 불가)

회전 동력계는 공구와 함께 돌기 때문에, 토크 Mz를 회전 한 바퀴 단위로 동기 평균하면 날 4개의 봉우리가 보일 것으로 기대했다.

- 일부 Cycle(예: Cycle 1 앞 절반)에서는 '한 바퀴에 4번 반복' 성분이 가장 커서 **날별 패턴이 실제로 존재**한다.
- 그러나 같은 Cycle 안에서도 패턴이 바뀌고, 마모 후반(예: Cycle 61)에는 '한 바퀴에 1번' 성분(공구 편심·런아웃)이 4배 성분의 2~7배로 압도한다.
- 8개 Cycle에서 봉우리 크기 차이와 라벨의 편마모 정도 사이에 관계가 보이지 않았다.
- 원인: ① 회전 위치 신호가 없어 녹화마다 날을 특정할 수 없음 ② 런아웃이 날별 힘 차이를 만듦 ③ 라벨 노이즈
- **결론: 공개 데이터로는 날별 분리 불가. 현장 적용 시 스핀들 엔코더(회전 각도) 신호를 함께 수집하면 가능할 것.**
